# Recipe Manager Full Stack Application

## Overview

Recipe Manager is a full-stack web application that allows users to create, view, update, and delete recipes.

The application demonstrates modern full-stack development using Angular, Spring Boot, and PostgreSQL.

---

## Tech Stack

### Frontend

* Angular
* TypeScript
* HTML
* CSS
* HttpClient
* Angular Routing

### Backend

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* REST APIs

### Database

* PostgreSQL

---

## Features

* Create Recipes
* View Recipes
* Update Recipes
* Delete Recipes
* Form Validation
* Error Handling
* Component-Based Architecture
* PostgreSQL Persistence
